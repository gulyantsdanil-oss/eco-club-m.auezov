# EcoPassport 5.4 — закрытая административная панель

Панель управляет существующими индивидуальными кодами учащихся. Она **НЕ предназначена для установки в опубликованный Apps Script-проект учеников**. Используйте отдельный Apps Script-проект, принадлежащий тому же владельцу закрытой Google Таблицы.

## Файлы

- `passport-admin-server.gs` → `Code.gs` нового Google Apps Script-проекта.
- `passport-admin-panel.html` → HTML-файл нового проекта с точным названием `AdminPanel`.

## Пошаговая установка

1. На https://script.google.com/home/projects/create создайте **НОВЫЙ** проект `Eco Club — Passport Admin`. Не открывайте для вставки действующий `Eco Club — Private Passport`.
2. Скачайте указанные два файла из GitHub через Raw или ZIP, откройте в Блокноте без автоматического перевода Яндекс Браузера.
3. В `Code.gs` вставьте содержимое `passport-admin-server.gs`.
4. Через `Файлы → + → HTML` создайте `AdminPanel` и вставьте содержимое `passport-admin-panel.html`.
5. В `Настройки проекта → Свойства скрипта` добавьте:
   - `ECO_SOURCE_SPREADSHEET_ID` = идентификатор существующей закрытой таблицы Eco Club;
   - `ECO_ADMIN_EMAIL` = адрес Google-аккаунта владельца таблицы, под которым вы откроете панель (значение не хранить в публичном GitHub).
6. Сохраните файлы и свойства. Выберите `Развернуть → Новое развёртывание → Веб-приложение`.
7. В настройках установите **Запуск от имени: Пользователь, открывший веб-приложение** и **У кого есть доступ: Только я**. Не используйте варианты «Все» или «Любой пользователь с аккаунтом Google».
8. После авторизации владельца откройте полученную ссылку `/exec`. Панель должна показать список участников с подтверждёнными вкладами, активные/неактивные коды и диагностику реестра.
9. Для проверки без риска для действующего первого кода выбирайте участника, которому код ещё не выдан. Выберите «Выдать код», скопируйте код из одноразового окна. Если нужна только проверка интерфейса, не выпускайте код.
10. Не сообщайте URL административной панели учащимся. С другого Gmail она **не должна открываться**.

## Что делает панель

- Показывает только участников, у которых есть подтверждённые вклады; отклонённые и тестовые строки исключаются из списка.
- Для каждого участника показывает факт наличия активного кода и сводную экологическую статистику.
- Выдаёт новый индивидуальный 64-символьный код. Открытый код показывается **один раз в интерфейсе**, а в Google Таблице хранится только его SHA-256-хэш.
- Заменяет прежний код, помечая прошлые активные коды недействительными.
- Отзывает все активные коды конкретного участника.
- Отображает агрегированные показатели качества записей: подтверждённые без ID, тестовые, совпадения по объёму и повторы ID. Совпадение объёма не означает доказанный дубль.

## Защита

- `doGet`, `admin54Overview`, `admin54Issue` и `admin54Revoke` **проверяют** текущий и эффективный Google-аккаунт на сервере.
- Если Google не предоставляет email или он не совпадает с `ECO_ADMIN_EMAIL`, сервер возвращает `ADMIN_ACCESS_DENIED`; **никакого автоматического обходного режима нет**.
- `ECO_ADMIN_EMAIL` должен совпадать с владельцем таблицы. Развёртывание «Пользователь, открывший приложение» + «Только я» рекомендуется в дополнение к серверной проверке.
- ФИО, классы, коды и хэши не включены в исходные файлы GitHub. Код не записывается в лист «Паспорт — выдача».
- Код, показанный после выпуска, находится в браузере до закрытия окна. Не делайте скриншоты с кодом и не отправляйте его в общие чаты.
- При случайном разглашении кода немедленно отзовите его и выдайте новый.
- Удалите ранее выданные открытые коды из старого листа «Паспорт — выдача» после защищённой передачи владельцам; **не удаляйте хэши из «Паспорт — доступ»**.
- Учёт индивидуальных вкладов и возможность выдачи доступа требуют соблюдения школьных требований к обработке персональных данных несовершеннолетних.

## Если появляется ACCESS_DENIED

Проверьте, что открыли приложение тем же Google-аккаунтом, что указан в `ECO_ADMIN_EMAIL`, и что выбрали `Запуск от имени — Пользователь, открывший приложение`. В отдельном браузерном профиле может быть выбрана другая учётная запись. Нельзя устранять ошибку удалением проверки админа или выбором публичного доступа.

## Обновление

Новые версии кода этого проекта переносите только в **административное** Apps Script-приложение. После редактирования используйте `Управление развёртываниями → Редактировать → Новая версия`. Ученический Apps Script и публичный ECO WORLD изменять не нужно.
