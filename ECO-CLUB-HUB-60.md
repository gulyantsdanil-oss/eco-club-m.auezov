# ECO CLUB HUB 6.0 — единый цифровой кабинет руководителя

## Назначение
Закрытое рабочее пространство для руководителя Eco Club в **том же Apps Script-проекте**, где уже работает административная панель Passport Admin.

**Это не новая открытая страница GitHub Pages.** Персональные данные и операции подтверждения остаются внутри закрытого Apps Script и приватной Google Таблицы. Ученический EcoPassport менять не нужно.

## Функции (доступны внутри одной страницы)

| Раздел | Что работает |
| --- | --- |
| Обзор | Количество участников, килограммы макулатуры, крышки, подтверждённые вклады, ожидающие заявки и вклады, рейтинг классов, задачи |
| Участники | Реальные участники с постоянными ID, вкладами и статусом кода; переход во внутренний раздел «Паспорта» |
| Заявки | Просмотр и поиск заявок, подтверждение новых, отклонение с обязательной причиной; сохраняет решение в таблицу и журнал |
| Вклады | Просмотр и поиск, подтверждение ожидающих или отклонение с причиной, запись даты и руководителя, журналирование |
| Мероприятия | Просмотр списка из листа «Мероприятия». Создание/редактирование пока не добавлено |
| Паспорта | Все функции старой панели: выдача, замена, отзыв кодов, сроки, синхронизация ID, включение еженедельных напоминаний |
| Контроль | Заявки и вклады, требующие внимания, отсутствующие ID, отклонённые записи, последние решения |
| Сайт | Внутренний предпросмотр главной страницы, ECO WORLD и публичной демо-страницы паспорта; при ограничениях встраивания — ссылка на сайт |

Дизайн двухколоночный на компьютере и адаптивный на смартфоне. Навигация между разделами **не требует открывать новые вкладки**.

## Безопасная установка в существующий проект

1. В проекте Apps Script **Eco Club — Passport Admin** сохраните резервные копии текущих `Код.gs` и `AdminPanel.html`. Ваша действующая Google Таблица остаётся прежней.
2. Скачайте GitHub ZIP: https://github.com/gulyantsdanil-oss/eco-club-m.auezov/archive/refs/heads/main.zip
3. Откройте файлы архива **через Блокнот**, не через автоперевод Яндекс Браузера (ранее перевод нарушал синтаксис кода).
4. Полностью замените содержимое **`Код.gs`** на содержимое **`passport-admin-server.gs`**.
5. Полностью замените содержимое **`AdminPanel.html`** на содержимое **`passport-admin-panel.html`**. Сохраните оба файла.
6. Убедитесь, что в Script Properties остались прежние значения **`ECO_SOURCE_SPREADSHEET_ID`** и **`ECO_ADMIN_EMAIL`**. Других свойств добавлять не требуется.
7. Выберите **Начать развёртывание → Управление развёртываниями → Изменить действующее развёртывание → Новая версия → Развернуть**. **Не создавайте новое развёртывание**, чтобы прежняя закрытая ссылка осталась действительной.
8. Проверьте настройки безопасности: **Выполнять от имени: Пользователь, открывший приложение**; **Доступ: Только я**.
9. Обновите ранее использовавшуюся ссылку `/exec` под Gmail владельца. Увидите заголовок **Eco Club | Цифровой кабинет** и восемь вкладок-**разделов внутри страницы**.

## Первый тест без изменения данных

- **Обзор**: отображаются цифры из Google Sheets.
- **Участники**: видны участники с ID, статистика и статусы кодов.
- **Заявки**: отображаются как уже принятые заявки, так и новые.
- **Вклады**: список отражает подтверждённые и отклонённые записи.
- **Паспорта**: старая панель управления кодами по-прежнему работает.
- **Контроль**: последние решения выводятся без контактных данных.
- **Сайт**: попробуйте «Главная», «ECO WORLD», «Паспорт · демо».

**Сначала ничего не подтверждайте и не отклоняйте.** Сверьте счётчики и убедитесь, что интерфейс функционирует. Затем одну реальную ожидающую заявку можно обработать с подтверждением руководителя. Обратное действие не предусмотрено этим интерфейсом: для исправления ошибки нужен отдельный административный процесс.

## Обработка заявок и вкладов

- Кнопки действия доступны только для статуса **«Новая заявка»** (лист «Заявки») или **«⏳ Ожидает»** (лист «Вклад»).
- При отклонении необходимо ввести причину.
- Перед записью сервер проверяет, что строка не изменилась со времени загрузки, и вновь проверяет исходный статус. Повторное решение отклоняется.
- Для вкладов используются существующие статусы **«✅ Подтверждено»** и **«❌ Отклонено»** (совместимы с проверкой данных таблицы).
- Каждое решение записывается в лист **«Журнал решений»**; для вкладов также пишутся дата и email подтвердившего.
- После подтверждения нового вклада нажмите **«Проверить и привязать новые вклады»** в разделе **«Паспорта»**, иначе новый вклад ещё не попадёт в личный кабинет с ID.
- Старые уже подтверждённые или отклонённые строки через этот интерфейс не изменяются.

## Границы первой версии

- «Мероприятия» пока **только для просмотра**.
- Редактирование HTML-кода/изображений опубликованного сайта, загрузка фото и настройка Google Forms остаются отдельными задачами разработки; сайт можно **просматривать** внутри кабинета, но не редактировать в iframe.
- Публичные игры ECO WORLD, EcoCraft, EcoLab и открытая статистика доступны через встроенный предпросмотр. Возможность встраивания зависит от ограничений браузера и сайта.
- Нет новых публичных серверных методов; административная панель по-прежнему доступна только владельцу.

## Проверка и восстановление

Вместе с кодом предыдущей версии сохранилась возможность откатиться к старому развёртыванию через **Управление развёртываниями → Изменить → Предыдущая версия**. Если интерфейс выдаёт ошибку, сначала проверьте, что код не был автоматически переведён браузером и обе версии файлов обновлены. В случае ошибок **не изменяйте доступ на «Все»** для диагностики.
