# EcoPassport 5.6 — контроль сроков кодов и еженедельные уведомления

Версия подготовлена в GitHub, но **не устанавливается в Google Apps Script автоматически**. Пользователь должен обновить **только** закрытый административный проект `Eco Club — Passport Admin`. Ученический проект `Eco Club — Private Passport`, публичный сайт ECO WORLD, данные участников и действующие коды **не меняются**.

## Новые возможности
- Индикаторы сроков действия: истекают в ближайшие **7** и **30** дней (группа 30 дней включает группу 7 дней), уже истекли, старые коды **без срока**.
- Статус на карточке каждого ученика — действительный до даты, истекает, истёк, старый без срока, отозван или не выдавался.
- Опциональные еженедельные напоминания руководителю по понедельникам, примерно в 08:00 **Asia/Almaty**. Google Apps Script может запускать таймеры с некоторым временным отклонением.
- Письмо отправляется **только если есть коды, требующие внимания**. Содержит агрегированные числа, без ФИО, классов, ID, хэшей или секретных кодов.
- Включение и выключение из закрытой панели; исходно рассылка **выключена**.

**Истечение срока уже обеспечивалось ученическим сервером EcoPassport 5.5**. Здесь добавлена лишь прозрачность и уведомления для руководителя.

## Что обновить
1. Сохраните резервные копии текущих `Код.gs` и `AdminPanel.html` на своём компьютере.
2. Откройте Google Apps Script → существующий проект **Eco Club — Passport Admin**. Не создавайте новый и не изменяйте `Eco Club — Private Passport`.
3. Скачайте оригинальные файлы из GitHub как ZIP и открывайте их через Блокнот (автоперевод Яндекс Браузера раньше портил JavaScript).
4. Полностью замените `Код.gs` содержимым файла `passport-admin-server.gs`.
5. Полностью замените `AdminPanel.html` содержимым файла `passport-admin-panel.html`.
6. Сохраните. Свойства `ECO_SOURCE_SPREADSHEET_ID` и `ECO_ADMIN_EMAIL` оставьте прежними.
7. Выберите **Начать развёртывание → Управление развёртываниями → Изменить текущее административное развёртывание → Новая версия → Развернуть**. Параметры остаются:
   - **Запуск от имени: Пользователь, открывший приложение**
   - **Доступ: Только я**
8. Откройте прежний адрес административной панели под Google-аккаунтом владельца. Должен появиться раздел «Сроки действия кодов» с показателями и кнопкой «Включить напоминания».
9. Проверьте, что списки участников, активные коды, выдача и отзыв отображаются как прежде. Для проверки интерфейса не нужно выпускать новый код.

## Как включить еженедельные письма (необязательно)

1. Перед включением убедитесь, что адрес владельца в свойстве `ECO_ADMIN_EMAIL` указан корректно.
2. В разделе «Сроки действия кодов» нажмите **«Включить напоминания»**.
3. Подтвердите запрос. Apps Script может запросить разрешения на создание триггеров и отправку писем. Если появится ошибка авторизации — перейдите в редактор Apps Script, проверьте и предоставьте только необходимые разрешения для созданного вами проекта, затем повторите попытку.
4. После успешного включения статус будет «Включены». Триггер запускается по понедельникам примерно в 08:00 в часовом поясе **Asia/Almaty**. Точное время не гарантируется платформой.
5. Чтобы остановить — нажмите **«Отключить»**. При этом удаляется только собственный триггер EcoPassport 5.6, другие автоматизации не затрагиваются.

**Важно:** никакие письма не отправляются до вашего явного нажатия «Включить напоминания». Не создавайте триггер вручную, чтобы не получить дубли.

## Как читать значения
- **До 7 дней** — активный, но скоро заканчивающийся код.
- **До 30 дней** — все активные коды, истекающие в ближайшие 30 дней, **включая** до 7 дней.
- **Без срока** — ранее выданные (до 5.5) коды, которые не имеют срока окончания; для них необходима плановая замена, без массового принудительного отзыва.
- **Истекли** — записи с активным флагом в реестре, но дата окончания прошла; ученический сервер их уже отклоняет.

## Безопасность
- Административные методы проверяют аккаунт владельца на сервере.
- Приватный триггер проверяет владельца через `Session.getEffectiveUser()` и отдельное свойство.
- Письма содержат только агрегаты, без персональных сведений.
- Не публикуйте URL закрытой административной панели, исходные секретные коды и данные учащихся.
- Для проверки инкогнито используйте чужой аккаунт: доступ к админпанели должен быть запрещён.

## Проверка
- Изменения не должны влиять на вход в уже выданные ученические паспорта.
- Открытие административной панели не отправляет писем.
- Просмотр сводки не выдаёт и не отзывает коды.
- Включение и отключение напоминаний — только по отдельному подтверждённому действию владельца.
